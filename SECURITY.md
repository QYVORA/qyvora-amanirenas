# Security Policy

## Supported Versions

Only the latest tagged release receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in Amanirenas, please report it privately by emailing the QYVORA OffSec team at **qyvorasec@gmail.com**. **Do not open a public GitHub issue.**

We will acknowledge receipt within 48 hours and provide an estimated timeline for a fix. Once the fix is released, we will credit the reporter (if desired) in the release notes.

## Contact

- **Website:** https://qyvora.org
- **Security contact:** qyvorasec@gmail.com
- **Organisation:** QYVORA OffSec — Tamale, Ghana

## Scope

This policy covers the Amanirenas source code, build pipeline, and release artifacts. Issues related to the mobile app profiles being analyzed (e.g., a vulnerability discovered *by* Amanirenas in an app) are out of scope — those should be reported to the app developer.

**Note:** Amanirenas performs offline static analysis only. It never executes app code or connects to live devices. Runtime assessment is not implemented.

## Responsible Disclosure

We ask that you give us reasonable time to patch and release a fix before any public disclosure.
